Controls

Control Description
Theme (moon/sun icon) Switch between dark and light mode
Keep screen on (monitor icon) Prevent the display from sleeping
Tick seconds (stopwatch icon) Switch between ticking and smooth second hand
Menu (MENU button) Open clock tools, settings, help, and site links

Timezones

Add ?tz= to the URL with any IANA timezone:

clocksimulator.com/?tz=America/New_York
clocksimulator.com/?tz=Europe/London
clocksimulator.com/?tz=Asia/Tokyo

Multi-clock dashboard

Show multiple clocks at once by separating timezones with commas. This automatically enables dashboardMode. Use &rows= to control the grid layout: 

clocksimulator.com/?tz=UTC,Europe/Helsinki,America/New_York
clocksimulator.com/?tz=UTC,Europe/Helsinki,America/New_York,Asia/Tokyo&rows=2 (dashboardMode)

You can also use the dashboard builder (MENU → Build dashboard) to visually add timezones and configure the grid.

Embedding

Embed the clock on any website via an <iframe>. Use the built-in embed builder (MENU → Embed) to configure, preview and copy the code.

Tips

Screen burn-in protection

To protect OLED and AMOLED displays, the clock subtly shifts its position every 10 minutes in a slow circular pattern. Dark Mode further reduces the risk of burn-in. Protection does not apply in embedded mode or when your device prefers reduced motion. Use ?burnin=false to disable.

Install as app (PWA)

This site works as a Progressive Web App. You can install it on your phone or computer for a full-screen clock and offline use. Use your browser’s menu (e.g. “Add to Home Screen” or “Install app”) to install.
